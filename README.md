# Kotova Taping Course — лендінг

Next.js 15 (App Router) + Tailwind CSS + TypeScript.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-збірка
```

## Як міняти контент

**Весь текст сайту — в одному файлі: `src/content.ts`.**
Ціни, модулі програми, відгуки, FAQ, контакти, тарифи — усе там.
Правиш цей файл, і зміни підхоплюються по всій сторінці.

## Секції (продающа структура)

| # | Блок | Компонент | Якір |
|---|---|---|---|
| — | Hero + біжучий рядок | `Hero.tsx` | `#top` |
| 1 | **Оффер** | `Offer.tsx` | `#offer` |
| 2 | **Болі ЦА** | `Pains.tsx` + `Audience.tsx` | `#pains` |
| 3 | **Страхи ЦА** | `Fears.tsx` | `#fears` |
| 4 | **Заперечення** | `Objections.tsx` + `Program.tsx` + `Benefits.tsx` | `#objections` |
| 5 | **Ціни** | `Pricing.tsx` | `#pricing` |
| 6 | **Соц пруфи** | `Author.tsx` + `Reviews.tsx` | `#proof` |
| 7 | **Відповіді на питання** | `Faq.tsx` | `#faq` |
| 8 | **Контакти** | `Signup.tsx` + `Contacts.tsx` | `#contacts` |

Програма курсу і «що отримаєш» стоять у блоці заперечень навмисно —
вони закривають заперечення «за що я плачу» перед тим, як людина побачить ціну.

## Ширина контейнера

Секції на всю ширину екрана. Класи в `globals.css`:

- `.wrap` — full-bleed, бічний відступ `clamp(1rem, 4vw, 4.5rem)`
- `.wrap-narrow` — для текстових блоків усередині широкої секції (max 72rem)

Довгі рядки тексту (FAQ, акордеон програми, заголовки) лишились обмеженими
по ширині навмисно — рядок на 2000+ px нечитабельний.









## Форма запису — модальне вікно

`SignupModal.tsx` — одна форма на всю сторінку, відкривається з будь-якої кнопки
запису через React-контекст. `SignupButton.tsx` — кнопка-обгортка, яка її викликає.

Підключені CTA: hero (`GlowButton`), оффер, квиток з ціною, підсумок чекліста болей.

Модалка вміє: блокування скролу, закриття по Escape і кліку на підкладку,
утримання фокуса всередині (Tab не вистрибує на сторінку), повернення фокуса
на кнопку після закриття, екран подяки з посиланням на Telegram.

Форма внизу сторінки (`Signup.tsx`) лишилась — для тих, хто просто доскролив.
Обидві шлють на той самий `/api/lead`.

## Вартість — один пакет

Курс продається одним пакетом за $499 (`content.ts` → `pricing.plan`).
`Pricing.tsx` малює його як квиток/чек: галочка зверху, ціна зі старою
закресленою, штрихові розділювачі з круглими виїмками, рядки чека,
список включеного у дві колонки і декоративний штрихкод унизу.

Квиток свідомо компактний, щоб уміщатись у висоту екрана цілком.
Якщо додаси пунктів у `includes`, він виросте — тримай список у межах 8.

## Секція «Знайомо?» — інтерактивний чекліст

`Pains.tsx` — картки болей клікабельні. Відмічені стають чорними з лаймовою
галочкою, а внизу виїжджає лаймова плашка з підсумком і кнопкою до тарифів.
Текст підсумку залежить від кількості відміченого (більше/менше трьох).

Стан живе тільки в пам'яті сторінки — нікуди не зберігається й не надсилається.

## Секція «Що зупиняє» — стопка карток

`Fears.tsx` використовує `stacking-cards` з [Fancy Components](https://fancycomponents.dev)
(встановлено через shadcn CLI, код у `src/components/fancy/blocks/`).

Картки прилипають до верху вікна й підтискаються одна під одну при скролі.
Висота секції (`h-[330vh]`) розрахована під 5 карток — якщо додаси/прибереш
страх у `content.ts`, підправ і її, інакше остання картка не встигне зафіксуватись.

## Картки «Для кого цей курс»

`GradientCard.tsx` — чорні картки з великою розмитою кольоровою заливкою, що
піднімається знизу й розчиняється в чорному (у стилі OpenMail-картки з референсу).
Зверху кругла іконка, далі заголовок і опис.

Додатково: 3D-нахил за курсором на motion, при наведенні заливка яскравішає
й іконка трохи збільшується.

Кольори заливки — масив `ACCENTS` у компоненті, по парі на картку.
Іконки — поле `icon` у `content.ts` → `audience.items`.

## Кнопка «записатись на курс»

`GlowButton.tsx` — жовта CTA з анімованим розмитим фоном: під поверхнею
повільно плавають три кольорові плями (жовта / салатова / рожева) під `blur-xl`.
При наведенні вони прискорюються втричі, яскравішають, і зліва направо
пробігає світловий блиск.

Все на чистому CSS (`@keyframes blob-a/b/c` у `globals.css`), без JS —
тому кнопка не додає ваги до бандла. `prefers-reduced-motion` вимикає рух.

## Анімовані компоненти

Через `shadcn` CLI з реєстру [Animate UI](https://animate-ui.com) (код лежить
у проєкті, не в node_modules — правиться вільно):

| Компонент | Де використано | Файл |
|---|---|---|
| `CountingNumber` | цифри в hero набігають при скролі | `animate-ui/primitives/texts/counting-number.tsx` |
| `HighlightText` | рожеве підсвічування заголовків секцій | `animate-ui/primitives/texts/highlight.tsx` |

Додати ще компонент:
```bash
npx shadcn@latest add "https://animate-ui.com/r/<item-name>.json"
```
Список усіх item-name: `curl -s https://animate-ui.com/r/registry.json | jq '.items[].name'`

Клас `.glow-card` у `globals.css` — анімована градієнтна рамка на тарифі PRO
(в стилі Uiverse, написано під нашу палітру на `@property --border-angle`).

Залежність: `motion` — використовується `CountingNumber` і `HighlightText`.



## Зв'язок — тільки Telegram

Телефон і WhatsApp прибрані з усієї сторінки. Telegram у шести місцях:
кнопка в хедері (десктоп + мобільне меню), друга CTA в hero, текст у запереченнях,
головна картка в контактах, футер.

Один юзернейм задається в `content.ts` → `brand.telegram` / `brand.telegramHandle`.

## Фото в hero

`public/hero/tape-1…6.jpg` — реальні фото аплікацій із папки «курс» на робочому столі.
Оброблені: HEIC → JPEG, обрізані у квадрат по центру, 900 px, ~110 КБ кожне (664 КБ разом).

Порядок карток задається масивом `CARDS` у `Hero.tsx` — там же `alt` кожного фото.
Щоб замінити: поклади новий файл у `public/hero/` і зміни `src` у потрібному об'єкті.

На мобільному ті самі фото показуються горизонтальною стрічкою під кнопками.

## Банери-перебивки

`Banner.tsx` — сплітовий банер: чорна картка з CTA + фото. Стоїть у трьох місцях:

| Де | Меседж | CTA веде на |
|---|---|---|
| після болей | «Вистачить клеїти навмання» | `#program` |
| після соц-пруфів | «Найближчий потік — 15 вересня» | `#pricing` |

Текст банерів — у `src/content.ts` → `banners`.

**Фото:** лежать у `public/banners/`.
- «Вистачить клеїти навмання» → `block-one.jpg`
- «Найближчий потік — 15 вересня» → `block-two.jpg`

Портрет викладачки — `public/about.jpg` (використовує `Author.tsx`).

Щоб підставити решту: поклади файл у `public/banners/` і в `content.ts`
заміни `image: null` на `image: "/banners/твій-файл.jpg"`.
Поки `null` — показується градієнтний плейсхолдер із підказкою.

Проп `reverse` міняє картку й фото місцями (середній банер іде дзеркально,
щоб три підряд не читались однаково).

## Форма заявки

Форма шле POST на `/api/lead`. Зараз заявка просто логується в консоль сервера.
Щоб отримувати заявки реально — відкрий `src/app/api/lead/route.ts` і розкоментуй
потрібний блок:

- **Telegram** — додай у `.env.local`:
  ```
  TELEGRAM_BOT_TOKEN=...
  TELEGRAM_CHAT_ID=...
  ```
- **Email через Resend** — додай:
  ```
  RESEND_API_KEY=...
  LEAD_EMAIL=you@example.com
  ```
